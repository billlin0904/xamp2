macOS 版如何安裝？+

下載 macOS v1.0.5（10/30 更新）安裝包，適用 Apple Silicon（arm64），需要 macOS 26.0 或更新版本；目前不支援 Intel Mac。

開啟 PKG 後，依原生安裝導覽完成安裝，再從「應用程式」開啟 XAMP2。App 與安裝包均已使用 Developer ID 簽署，但 Apple 公證尚未完成，macOS 可能阻擋安裝或開啟。

2026-10-30 更新：加入 Apple 原生毛玻璃與黑膠模式，放大清單和次要資訊字體，並修正 A 鍵／注音 ㄇ被全域快捷鍵攔截的問題。已檢查 Release 建置、套件簽章及封裝內容；原生材質、快捷鍵與黑膠模式測試通過。實體 DAC 相容性仍需依裝置確認。版本說明。下載 SHA-256 校驗檔

Linux 版如何下載與啟動？+

下載 Linux x86_64 測試版 ZIP，適用 Ubuntu 22.04（glibc 2.35 或更新版本）；其他發行版尚未驗證。解壓縮到可寫入的資料夾後，在終端機執行：

chmod +x linux-x64/XAMP.AppDir/AppRun linux-x64/XAMP.AppDir/usr/bin/xamp linux-x64/XAMP.AppDir/usr/bin/xamp.bin
./linux-x64/XAMP.AppDir/AppRun

請保留整個 AppDir，使用 AppRun 啟動。套件不含個人資料庫或設定；首次執行會自動建立。

已通過 16 項 Linux PCM／DoP 回歸測試、328 個 ELF 相依檢查，以及移至獨立目錄後的主視窗初始化測試；實際播放與硬體輸出仍待人工驗證。Linux 提供 PulseAudio、PipeWire 與 ALSA 後端；WASAPI、ASIO 與 Windows 背景材質僅適用 Windows。

WSL 請先開啟 Ubuntu 終端機。若只有工作列圖示、視窗透明且標題帶有 COPY MODE，請參考 Linux 使用說明與 WSL 排錯。

如何開啟 Windows 11 透明背景？+

在「設定 → 播放 → 背景材質」選擇 Mica 或 Acrylic。Mica 提供較柔和的系統背景材質；Acrylic 是毛玻璃般的模糊與透色效果；關閉則使用一般實色背景。

需要 Windows 11 22H2 或更新版本，並在 Windows「設定 → 個人化 → 色彩」開啟透明效果。高對比模式、關閉透明效果或不支援的系統會使用實色背景。文字、封面與控制項保持可讀性，實際效果依桌布與視窗後方內容而異。

BitPerfect 與 PCM 轉 DSD 要怎麼設定？+

在「設定 → 輸出」啟用 BitPerfect PCM，選擇 WASAPI 獨佔或 ASIO 裝置，下次播放生效。需要轉換時再啟用 PCM2DSD。BitPerfect 模式略過軟體音量，請使用 DAC 或外部設備調整音量。

裝置必須支援來源取樣率與有效位元；DSD 另需相容的驅動與 DAC。自動測試涵蓋整數解碼、位元排列及 FIFO 傳遞，尚未完成實體裝置迴路驗證。閱讀技術文件。

可以從原始碼編譯嗎？+

可以。Windows 開發環境使用 Visual Studio 18、MSVC、Qt 6.8.3，以及 FFmpeg、BASS／BASS FX、ASIO SDK 等第三方元件。核心使用 C++20／C++23，元件路徑需依本機環境調整。

開啟 src/xamp/xamp.sln，選擇 Release | x64 建置。執行時還需 Qt runtime、plugins、components 與資源，單獨複製執行檔不足以執行。
