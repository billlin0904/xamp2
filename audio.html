BitPerfect PCM

16 / 24 / 32-bit

Windows 版以 WASAPI 獨佔或 ASIO 播放支援的立體聲整數 PCM WAV、FLAC，保留原始取樣率與有效位元，略過 EQ、重取樣及軟體音量。

PCM → DSD

DoP / Native DSD

Windows 版在 BitPerfect PCM 播放路徑啟用轉換，可設定 DSD 倍率、升頻濾波器、調變器、輸入增益與 Dither。依驅動及 DAC 支援選擇 DoP 或 ASIO Native DSD。

轉換後輸出為 DSD，並非原始 PCM 位元直通。

Windows 輸出WASAPIASIOXAudio2

Linux 提供 PulseAudio、PipeWire 與 ALSA 後端，包含 ALSA／PipeWire 整數 PCM 與 ALSA PCM→DSD／DoP 支援。實體 DAC 相容性仍待驗證，詳見 Linux 使用說明。

BitPerfect 與 PCM 轉 DSD 要怎麼設定？+

在「設定 → 輸出」啟用 BitPerfect PCM，選擇 WASAPI 獨佔或 ASIO 裝置，下次播放生效。需要轉換時再啟用 PCM2DSD。BitPerfect 模式略過軟體音量，請使用 DAC 或外部設備調整音量。

裝置必須支援來源取樣率與有效位元；DSD 另需相容的驅動與 DAC。自動測試涵蓋整數解碼、位元排列及 FIFO 傳遞，尚未完成實體裝置迴路驗證。閱讀技術文件。
